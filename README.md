# 📚 Conceitos Utilizados
Expo Router (navegação baseada em arquivos)<br>
router.push() e router.back()<br>
Passagem de parâmetros (params)<br>
useLocalSearchParams()<br>

# EXERCÍCIO 1 - App de 3 Telas (Fácil)
### Crie um app com navegação entre 3 telas.<br>
Requisitos:<br>
Tela 1 (/): Título "Bem-vindo" + Botão "Ir para Tela 2"<br>
Tela 2 (/tela2): Título "Segunda Tela" + Botões "Ir para Tela 3" e "Voltar"<br>
Tela 3 (/tela3): Título "Terceira Tela" + Botão "Voltar ao Início"<br>

# EXERCÍCIO 2 - Catálogo de Produtos (Médio)
### Crie um catálogo com lista e detalhes.
Requisitos:<br>
Tela Lista: 3 produtos com nome, preço e botão "Ver Detalhes"<br>
Tela Detalhes: Recebe nome, preço e descrição via params<br>

# EXERCÍCIO 3 - Perfis de Usuário (Médio)
### Crie uma tela com 3 botões de perfis diferentes.
Requisitos:<br>
Tela inicial com 3 botões (um para cada pessoa)<br>
Cada botão navega para /perfil passando: nome, idade, cargo<br>
Tela Perfil mostra os dados recebidos + foto gerada<br>
